# Networking Fundamentals Lab

## About This Repository

This repository contains five practical networking labs completed using Cisco Packet Tracer.

The projects demonstrate the development of foundational networking knowledge through the design, configuration, testing and troubleshooting of different network environments.

The portfolio progresses from basic local area network configuration to more advanced concepts involving routing, DHCP, DNS, VLAN segmentation and inter-VLAN communication.

Each lab includes its own documentation and network topology evidence.

## Lab Overview

| Lab | Project | Difficulty |
|---|---|---|
| 01 | Basic LAN Configuration | Beginner |

| 03 | DHCP & DNS Configuration | Intermediate |
| 04 | VLAN Segmentation | Intermediate |
| 05 | Inter-VLAN Routing | Intermediate |

## Practical Projects

### Lab 01 — Basic LAN Configuration

Building a basic local area network by connecting end devices through a switch, configuring IPv4 addressing and testing connectivity between devices.

[View Lab 01](01-basic-lan/)

### Lab 02 — Routed Network Configuration

Configuring a network with multiple subnets using a router, switches and end devices. Focuses on IP addressing, default gateways and communication between different networks.

[View Lab 02](02-routed-network/)

### Lab 03 — DHCP & DNS Configuration

Exploring automatic IP address assignment through DHCP and domain name resolution through DNS.

[View Lab 03](03-dhcp-dns/)

### Lab 04 — VLAN Segmentation

Configuring Virtual Local Area Networks (VLANs) to logically separate devices within a network and exploring access ports and trunking.

[View Lab 04](04-vlan-segmentation/)

### Lab 05 — Inter-VLAN Routing

Configuring communication between separate VLANs through inter-VLAN routing, allowing devices on different network segments to communicate.

[View Lab 05](05-inter-vlan-routing/)

## Troubleshooting Experience

Troubleshooting activities were incorporated throughout the five labs.

This involved investigating network connectivity issues, identifying configuration problems, testing possible solutions and verifying that network communication was restored.

## Learning Objectives

These projects were completed to develop practical networking skills and establish a foundation for further learning in IT support, network administration and cybersecurity.
